# 命令

所有命令统一 `g2` 前缀，避免与现有 `/grok`、`/grok生图`、`grok_web_search` 冲突。
一经匹配立即 `event.stop_event()`；参数错误也由插件明确回复，不让默认 LLM 再处理。

## `/g2搜索 <问题>`（别名 `/grok2搜索`）

- 强制执行全局已启用的 Web/X 联网搜索，返回正文和结构化来源；两个开关都关闭时在请求前拒绝。
- 搜索成功后，插件使用当前会话的 AstrBot 聊天模型进行一次独立整理；不携带会话历史或工具，正文仅基于检索材料，来源仍由插件本地追加。整理失败时自动发送原始结果。
- `grok2api_web_search` Tool 保持返回结构化结果，交由调用它的 AstrBot 主模型组织回复，不触发这次整理。
- 内容长度 1–4000 字符。
- `show_search_sources=false` 或 `max_search_sources=0` 时不输出来源；否则最多 `max_search_sources` 条，格式 `标题 - URL`。

示例：

```
/g2搜索 2026 年诺贝尔物理学奖得主
```

## `/g2生图 <提示词>`（别名 `/grok2生图`）

- 命令后的整段文本都是提示词；数字、比例和连续空格不会被命令解析器拆分。
- 每次命令固定请求 1 张图片。提示词处理关闭时，原文直传，上游参数为 `1k` 且不传比例。
- 提示词处理为“整理”或“优化”时，会先调用配置的 AstrBot 文本模型：整理仅补全比例与 `1k/2k`，优化可改写提示词并补全参数。
- 任务锁取得后默认先发送一次生成提示；成功只发送媒体，不另发成功文字。

示例：

```
/g2生图 一只戴帽子的橘猫
```

## `/g2改图 <编辑要求>`（别名 `/grok2改图`）

- 编辑当前消息或回复链中的**第一张**图片。
- 必须附带图片或回复一条带图片的消息，否则提示“请附带或回复一张图片”。
- 不支持 `--image-url`；该参数出现在改图命令中会直接拒绝，不会被当作编辑提示词。
- 输入图片会归一化为 PNG/JPEG 并经防解压炸弹检查。
- 输入图片校验和提示词处理完成后默认先发送一次编辑提示；提示文本不包含参考图或提示词处理状态。

示例：

```
/g2改图 把背景改成雪景
```

## `/g2视频 <提示词>`（别名 `/grok2视频`）

- 命令后的整段文本都是提示词；不再使用时长、比例前缀。
- 提示词处理关闭时，原文直传，默认 `6s`、`720p`；无参考图时不传比例。消息或回复参考图会在处理器没有给出比例时自动匹配最近支持比例。整理模式仅补全参数；优化模式也可改写提示词。
- 支持比例为 `1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`；视频时长仅 `6s`、`10s`、`15s`，分辨率仅 `480p`、`720p`、`1080p`。模型返回其他值会明确拒绝本次生成。
- 可选单图引导：附带或回复图片时作为首帧。
- 也可显式传入 URL 参考图：`/g2视频 --image-url <HTTPS_URL> <提示词>` 或 `/g2视频 --image-url=<HTTPS_URL> <提示词>`。显式 URL 优先于消息图片；只接受外部 HTTPS 域名，不接受 userinfo、fragment、单标签主机、`localhost`、`.localhost`、`.local` 或 IP 字面量。URL 可能带签名 query，插件不下载、不 DNS 解析、不记录，也不传给提示词模型；因此不会自动识别外链图片比例，上游负责最终下载与重定向安全。
- 任务在参考图和提示词处理均成功后默认先发一条固定进度提示，完成后发视频，共 2 条回复；进度提示不解释参考图或提示词处理状态。

示例：

```
/g2视频 海边日落，16:9，10 秒，1080P
/g2视频 竖屏城市夜景
/g2视频 一只奔跑的狗
/g2视频 --image-url https://example.com/reference.jpg 让他跳舞
```

## `/g2面板`（别名 `/grok2面板`，需 AstrBot ADMIN）

- 按 `advanced_settings.panel_sections` 所选块，以 `panel_period` 为区间发送账号池、图片库、视频库、请求审计汇总、按模型统计的聚合。仅 AstrBot 管理员可用。
- 不需要 API Key：只要配置了 `admin_username`/`admin_password` 与 `api_base_url` 即可使用（管理面凭据与搜索 API Key 相互独立）。
- `panel_sections` 留空时发送一条"未启用任何面板数据块"的说明，不发起任何管理请求。
- 只读管理端点；数据取自脱敏聚合，不输出账号邮箱、API Key 名、请求 ID 或原始审计记录。
- 账号/媒体/审计摘要每块各一次 GET；请求审计汇总还会从审计列表安全聚合请求类型、Provider、计量来源、流式、重试、工具和媒体字段。调用趋势与按模型统计复用同一批审计行，不增加管理请求；趋势使用 UTC 时间轴，`24h` 按小时、`7d` 按 6 小时、`30d` 按天、`90d` 按周展示。
- 审计列表最多保留 5000 条，超出自带截断说明；若列表接口覆盖范围小于汇总接口，面板会显示 `覆盖 X/Y`，趋势和行为统计只代表已获取的审计行，不会把局部明细当成全量。
- 取回结果缓存 60 秒；登录/会话失败返回一条稳定非敏感错误，单块失败不影响其余所选块。
- 默认通过 AstrBot 已配置的 HTML-to-image 服务渲染为 1920x1080（16:9）图片；可通过 `panel_resolution` 选择 720p、1080p 或 1440p。若渲染服务不可用或返回非图片内容，自动退回纯文本；不使用 Playwright。
- 背景每次发送都会随机打乱 Wallhaven（动漫、SFW、16:9）、LoliAPI 横屏和 t.alcy 横屏的刷新顺序，各站点均随机取图；所有来源经过横向图片校验。来源不保证排除 AI 图片。单个图源失败后继续剩余图源，全部失败时复用最近缓存，缓存也不可用时使用内置背景。

## `/g2面板订阅` 与 `/g2面板退订`（均需 AstrBot ADMIN）

- 订阅命令将当前消息的 UMO 写入插件数据目录；退订只移除当前 UMO。
- 不显示或在日志中输出完整 UMO。`/g2面板订阅列表` 只显示当前会话状态、命令订阅数和固定配置目标数。

## 面板定时推送

- 在 `advanced_settings` 同时提供全局五段 Cron 和从每日 00:00 对齐的间隔分钟数，二者可以同时启用。
- 固定配置目标与命令订阅目标合并去重；相同 UMO 在同一自然分钟只尝试发送一次。
- 定时任务直接调用面板取数、T2I 和 `Context.send_message`，不请求 AstrBot 主 LLM。平台无法恢复已订阅会话时发送会失败且不自动重试；QQ Official 在重启后通常需要目标会话先有一条入站消息供 AstrBot 恢复场景。

## `/g2帮助`（别名 `/grok2帮助`）

- 输出命令说明和当前启用能力，所有人可用。
- 动态显示各能力状态（可用/未配置/未知），不泄露搜索模型名单、密钥或凭据。

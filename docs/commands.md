# 命令

所有命令统一 `g2` 前缀，避免与现有 `/grok`、`/grok生图`、`grok_web_search` 冲突。
一经匹配立即 `event.stop_event()`；参数错误也由插件明确回复，不让默认 LLM 再处理。

## `/g2搜索 <问题>`（别名 `/grok2搜索`）

- 强制执行已启用的 Web/X 联网搜索，返回正文和结构化来源。
- 内容长度 1–4000 字符。
- 来源最多 `max_search_sources` 条，格式 `标题 - URL`。

示例：

```
/g2搜索 2026 年诺贝尔物理学奖得主
```

## `/g2生图 [数量] <提示词>`（别名 `/grok2生图`）

- `[数量]` 可选，默认 1，范围 1 到 `max_images_per_request`。
- QQ Official 运行时固定上限 4 张，超出在调用 API 前拒绝。
- 成功只发送媒体，不另发成功文字。

示例：

```
/g2生图 2 星空下的城市
/g2生图 一只戴帽子的橘猫
```

## `/g2改图 <编辑要求>`（别名 `/grok2改图`）

- 编辑当前消息或回复链中的**第一张**图片。
- 必须附带图片或回复一条带图片的消息，否则提示“请附带或回复一张图片”。
- 输入图片会归一化为 PNG/JPEG 并经防解压炸弹检查。

示例：

```
/g2改图 把背景改成雪景
```

## `/g2视频 [时长] [比例] <提示词>`（别名 `/grok2视频`）

- `[时长]` 可选，1–15 秒，默认 6。
- `[比例]` 可选：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`3:2`、`2:3`。
- 可选单图引导：附带或回复图片时作为首帧。
- 默认先发一条“视频正在生成”，完成后发视频，共 2 条回复。

示例：

```
/g2视频 8 16:9 海边日落
/g2视频 9:16 竖屏城市夜景
/g2视频 一只奔跑的狗
```

## `/g2状态`（别名 `/grok2状态`，需 AstrBot ADMIN）

- 输出 Base URL、TLS 校验、Client Key 是否配置、启用能力、搜索候选顺序、当前可见/不可见候选、模型目录状态、接口耗时。
- 只调用 `GET /v1/models`，**不**执行真实搜索探针、不消耗搜索生成。
- 目录失败显示稳定错误码（如 `network_error`），不显示"可见模型数 0"。
- 不泄露 Key、模型权限、代理凭据或完整异常响应。

## `/g2帮助`（别名 `/grok2帮助`）

- 输出命令说明和当前启用能力，所有人可用。
- 动态显示各能力状态（可用/未配置/未知），不泄露搜索模型名单、密钥或凭据。
